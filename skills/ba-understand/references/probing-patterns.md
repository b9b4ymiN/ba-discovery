# Answerable Probing Patterns

Transform questions without losing the decision being tested.

Instead of “What is your prioritization objective function?” ask:
> “If there is not enough material for every order, what usually decides which one goes first?”

Instead of “What consistency model is required?” ask:
> “If two people change this information almost at the same time, what outcome would be unacceptable?”

Use this sequence only as needed:
1. concrete scenario,
2. real example from the stakeholder's work,
3. contrast between two meaningful choices,
4. consequence if the choice is wrong.

Do not teach a specialist domain merely so the stakeholder can answer a question that should have been transformed or researched.
