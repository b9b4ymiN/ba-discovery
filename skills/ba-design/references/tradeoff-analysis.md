# Architecture Trade-off Analysis

For a material choice:
1. state the decision and design driver,
2. compare 2–3 viable options where real alternatives exist,
3. evaluate consequences against confirmed requirements/constraints,
4. call out assumptions and uncertainty,
5. recommend one option with rationale,
6. record the confirmed decision and revisit conditions.

Avoid decorative option lists. If one option is clearly dominated by approved constraints, say so.
