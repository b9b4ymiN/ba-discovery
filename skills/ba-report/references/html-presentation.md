# HTML Report Operational Notes

The canonical visual system is `../assets/report-template.html`. Do not duplicate its CSS here.

When producing HTML:

- copy/fill the fixed template rather than redesigning it,
- keep the file self-contained and offline-readable,
- preserve all 15 semantic section containers,
- keep `Not applicable in the current approved scope` for non-applicable sections rather than deleting them,
- verify print readability and that no remote CSS/font/script dependency was introduced,
- preserve approved meaning when simplifying a visual explanation.
