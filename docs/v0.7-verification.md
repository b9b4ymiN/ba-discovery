## Portability gate

The correctness-bearing paths (`skills`, `shared`, `scripts`, `evals`, `examples`, `.claude-plugin`) contain no required `context: fork` dependency. Core scenarios and run records use vendor-neutral event names and free-text runtime/model metadata.

`scripts/ba_eval.py` uses Python standard library only and does not call an AI/model API.

## Result semantics

Behavioral results are criterion-level:

- `PASS`
- `FAIL`
- `NOT_OBSERVED`
- `NOT_APPLICABLE`

There is no aggregate Evidence Grade. Semantic judgments are emitted as explicit review prompts rather than fabricated machine verdicts. `must_pass_unobserved` separately exposes missing evidence/telemetry so an unobservable must-pass criterion cannot be mistaken for a confirmed pass.
