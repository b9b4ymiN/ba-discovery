# v0.8 `/ba-change` Skill TDD Evidence

## RED — observed before the skill existed

The v0.8 design conversation itself exposed repeatable failures before `/ba-change` guidance was written:

1. **Single-user drift.** The assistant twice introduced another human participant (for example a manager/approver) even though BA Discovery had already been constrained to one interactive user. The user corrected this explicitly. This is the failure targeted by the Single User Only contract and `USR-01`.
2. **Change over-fragmentation.** The assistant proposed separating “combine orders to satisfy MOQ” into a new change because it was a separable decision. The user corrected that it belonged to the same MOQ business concern. This is the failure targeted by business-intent-anchored Change Identity and `CHG-02`.
3. **Relation by reconstruction instead of re-reading active state.** The assistant initially leaned toward broad semantic/dependency reconstruction. The user redirected the design to open and read the actual currently-open change records first, then review the relation only between the open change(s) and the new intent. This is the failure targeted by Read before relating and `CHG-01`.

These failures are sufficient RED evidence: without the v0.8 skill/contract, the model can drift into multi-user assumptions, decision-level change splitting, or overly broad reconstruction.

## GREEN

The new `/ba-change` skill and shared contracts now encode Single User Only, business-intent change identity, Read before relating, staged mutation, Minimum Revalidation, and post-commit verification. Static skill-contract tests pass. The v0.8 behavioral fixture suite includes explicit good/bad cases for same-change extension, new business concern, pending-truth leakage, provisional dependencies, single-user behavior, verified commit ordering, and resume behavior.

This runtime did not expose a fresh-agent/subagent dispatcher, so pressure re-runs with independent model instances could not be executed here. The RED evidence above is from the actual pre-skill design conversation; deterministic and stored behavioral fixtures provide the portable regression layer for this release.
