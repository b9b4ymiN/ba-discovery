## Contract checks covered

- exactly seven user-facing skills remain,
- phase vocabulary is unified for current state,
- shared contracts live at plugin root,
- Question Contract is shared by reasoning phases,
- approval provenance is required for v0.6+ approved snapshots,
- deterministic lint checks structural invariants only,
- `/ask-ba` has BA / Engineering / No-BA exits and read-only tool restrictions,
- `/ba-report` uses a fixed self-contained HTML shell,
- the complete example includes Project Brain, four approved snapshots, and a generated report,
- English and Thai READMEs document Question Quality + State Integrity.
