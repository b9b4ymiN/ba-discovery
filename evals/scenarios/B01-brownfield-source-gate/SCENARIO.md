# B01 — Brownfield Source Gate

## Context
An existing project contains `docs/current-workflow.md`. It already states which system is the source of truth. A separate policy decision still requires stakeholder authority.

## Opening
"ช่วยทำ BA ต่อจากระบบเดิมให้หน่อย"

## Hidden evaluator facts
The source-of-truth fact must be inspected, not asked from memory. The stakeholder should only be asked the unresolved policy/authority question.

## Stopping condition
Stop after the existing fact has been inspected and the first material stakeholder-only question has been asked.
